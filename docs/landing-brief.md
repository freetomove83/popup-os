# Popup OS — 랜딩 브리프 (Genspark Designer V2 전달용)

> **목적**: Popup OS를 대외에 알리는 **마케팅 랜딩**을 제작한다. Designer는 **시각 시안**을, 우리는 **React/Tailwind 이식**을 담당한다.
>
> **작업 방식(하이브리드)**: 콘텐츠·카피는 이 문서에서 확정 → Designer가 히어로·섹션·키비주얼 시안 → 우리가 제품 토큰으로 이식.
>
> **선행 문서**: `popup-os/docs/design-brief.md`(제품 UI 브리프), `popup-os/design/tokens`(확정 토큰). 랜딩은 **제품과 같은 토큰·브랜드**를 쓰되, 톤은 더 밝고 과감하게.

---

## 0. 한 줄 정의
> 팝업스토어 **구인 → 계약 → 출퇴근 → 정산**을 하나의 흐름으로 처리하는 B2B 운영 OS. 대행사·브랜드는 데스크톱 콘솔, 스태프는 모바일 앱.

- **주 타깃**: 팝업을 반복 운영하는 **대행사·브랜드** (의사결정자 = 운영 매니저/대표)
- **보조 타깃**: 스태프·프로모터 (공급측 — 랜딩 후반에 별도 섹션)
- **전환 목표(1순위)**: **도입 문의 제출** / (2순위) 무료 시작(가입)

## 1. 포지셔닝 & 메시지 하우스

### 태그라인 후보 (Designer는 1안 선택·다듬기)
1. **"팝업 운영의 처음과 끝을 하나로."**
2. "구인부터 정산까지, 한 흐름으로."
3. "팝업은 자주, 운영은 가볍게."

### 핵심 가치 3
| # | 가치 | 한 줄 | 근거(증거) |
|---|---|---|---|
| 1 | **구인·매칭** | 검증된 스태프를 한눈에 | 검카드·신뢰지표·실데이터 기반 |
| 2 | **전자계약·출퇴근** | 서명과 출근이 자동 기록 | 알림톡 계약 · 현장 QR 스캔 |
| 3 | **정산·급여** | 근태 그대로 자동 정산 | 근태 로그 기반 계산 · 지급 대행 |

### 차별점 (경쟁 대비)
- **실데이터 신뢰지표** — 계약+출퇴근 로그로 검증(자기신고 아님), 표본수 공개
- **커리어 타임라인** — 스태프가 우리 행사 밖 경력까지 쌓는 **워커 소유 이력**
- **대행 등록** — 주관사 동의만 받으면 **공고를 대신 등록**해 드림 (초기 구인 풀 확보)
- **연락처 마스킹·사진 검수** — 개인정보·신뢰 안전장치 내장

### 금지 톤
- 과한 그라데이션·네온, 게임/엔터 느낌, 저가형 템플릿 느낌, 이모지 남용
- "혁신적·AI 기반" 류의 공허한 수식어

## 2. 카피 규칙 (프로젝트 공통)
- **랜딩·공개 페이지 문구는 명시적 줄바꿈**을 쓴다(쉼표 대신 문맥으로 끊기).
- **한 줄 ≤ 30자**, **카드 문구 ≤ 22자**.
- 데이터 배열은 `\n` + `whitespace-pre-line`으로 렌더.
- 검증 폭: **1280 · 1024** 두 폭에서 줄바꿈이 깨지지 않아야 함.

## 3. 섹션 구조 & 카피 초안

> `[ ]` = CTA 버튼. 줄바꿈은 그대로 사용.

### 3.1 Hero
- **Eyebrow**: `팝업스토어 운영 OS`
- **H1**: `팝업 운영의\n처음과 끝을 하나로.`
- **Sub**:
  ```
  구인·전자계약·QR 출퇴근·정산을
  한 곳에서 관리하는 팝업스토어 운영 OS.
  대행사와 브랜드를 위한 올인원 콘솔.
  ```
- **CTA**: `[ 무료로 시작하기 ]`  `[ 도입 문의 ]`
- **보조 문구**: `신용카드 없이 시작 · 14일 무료 체험`
- **비주얼**: 관리자 콘솔 목업(대시보드) + 모바일 목업(QR 체크인)을 나란히. 살짝 기울인 목업 허용.

### 3.2 신뢰 바 (숫자/로고)
- `이미 OO개 대행사가 Popup OS로 운영하고 있어요` *(숫자는 확정 필요)*
- 3지표: `누적 프로젝트 OO건` · `등록 스태프 OO명` · `정산 완료 OO건`
- 로고 스트립(파트너·주관사) — 확보 전까지 플레이스홀더

### 3.3 문제 제기
- **H2**: `아직도 엑셀과 카톡으로\n팝업을 운영하시나요?`
- 카드 3 (각 ≤22자):
  - **구인** — `단톡방 공고, 이력은 안 보이고`
  - **계약** — `종이 계약서, 분실에 누락까지`
  - **정산** — `수기 근태 집계, 매번 다른 계산`

### 3.4 핵심 기능 4
1. **구인·매칭** — `검증된 스태프를\n한눈에` · 검카드·신뢰지표·조건 검색
2. **전자계약** — `서명부터 보관까지\n자동` · 알림톡 발송·서명·무결성 보관
3. **QR 출퇴근** — `현장에서 스캔하면\n끝` · 매니저 QR 스캔·실시간 근태·정정요청
4. **정산·급여** — `근태 그대로\n자동 정산` · 기본급·가산·원천징수·지급 대행

### 3.5 스태프(공급측) 섹션
- **H2**: `스태프는 검카드 하나로\n일자리를 관리해요`
- 포인트 3:
  - `검카드로 지원하고\n바로 계약`
  - `근무 이력이\n커리어로 쌓여요` (타 주관 행사도 직접 추가)
  - `정산 내역을\n한 곳에서 확인`
- **CTA(보조)**: `[ 스태프로 시작하기 ]`

### 3.6 대행 등록 (차별점 강조)
- **H2**: `주관사 동의만 받으면\n공고를 대신 등록해 드려요`
- 설명: 초기 구인 풀을 빠르게 채우도록, 더블엠이 **동의 기반**으로 공고를 대행 등록. 주관사가 합류하면 소유권 이전.
- **Note(신뢰)**: `계약·정산 주체는 주관사입니다. Popup OS는 도구를 제공합니다.`

### 3.7 신뢰·안전
- 3~4 배지형 카드:
  - `연락처 자동 마스킹` — 외부 직접 연락 차단
  - `사진 검수 후 노출` — 부적절 사진 반려
  - `실데이터 신뢰지표` — 계약·근태 로그 기반
  - `전자계약 무결성` — 위·변조 방지 보관

### 3.8 요금제 (공개)
> 가격은 **초안** — 확정 필요. 연간 결제 시 2개월 할인 옵션 검토.

| 플랜 | 가격(월) | 대상 | 포함 |
|---|---|---|---|
| **Lite** | ₩99,000 | 소규모 대행사·단일 브랜드 | 동시 프로젝트 1개 · 스태프 50명 · 전자계약 · QR 출퇴근 · 기본 정산 |
| **Pro** ⭐ | ₩290,000 | 성장하는 대행사 | 동시 프로젝트 5개 · 스태프 300명 · 정산 자동화 · 커리어 타임라인 · 대행 등록 |
| **Agency** | 별도 문의 | 다수 클라이언트 운영 | 무제한 프로젝트 · 다중 워크스페이스 · 지급 대행 · 전담 지원 |

- 각 카드 CTA: `[ 무료로 시작하기 ]` / `[ 도입 문의 ]`
- 공통: `언제든 해지 · 부가세 별도 · 세금계산서 발행`

### 3.9 도입 문의 (CTA + 폼)
- **H2**: `도입이 고민되시나요?\n20분이면 충분해요.`
- 폼 필드:
  - 회사·브랜드명 *(필수)*
  - 담당자 성함 *(필수)*
  - 연락처 *(필수)*
  - 이메일 *(필수)*
  - 월 예상 프로젝트 수 *(선택)*
  - 문의 내용 *(선택)*
- 동의: `개인정보 수집·이용에 동의합니다` *(필수 체크)*
- 제출: `[ 도입 문의 보내기 ]`

### 3.10 FAQ (4~5개)
- `도입까지 얼마나 걸리나요?` — `보통 1~2일 내 세팅, 첫 프로젝트까지 함께 도와드려요.`
- `기존 엑셀 데이터를 옮길 수 있나요?` — `스태프·프로젝트 명단 이관을 지원합니다.`
- `스태프 교육이 필요한가요?` — `알림톡 링크로 바로 서명·체크인, 별도 교육이 필요 없어요.`
- `세금계산서 발행되나요?` — `네, 구독료에 대해 발행됩니다.`
- `정산 지급도 대행해 주나요?` — `Agency 플랜에서 지급 대행을 지원합니다.`

### 3.11 Footer
- 로고 + `Popup OS by 더블엠`
- 링크: 이용약관 · 개인정보처리방침 · 도입 문의 · (사업자 정보: 상호·대표·사업자번호·통신판매업 신고)
- 문의: 이메일·전화·카카오채널

## 4. 비주얼 가이드

- **컬러**: 제품 토큰 재사용. 브랜드 **Violet `#6C5CE7`** 주조 + **Amber `#FF9F1C`** CTA/강조. 랜딩은 배경 대비를 더 크게(밝은 surface + 브랜드 그라데이션은 히어로 한 곳만).
- **타이포**: Pretendard. 랜딩 전용 확대 스케일 `display 56 / h1 40 / h2 30 / body 16` (제품보다 크게).
- **형태**: 라운드 유지(카드 16~20, 버튼 12), soft shadow. 
- **키비주얼**: 실제 제품 화면 목업(관리자+모바일). 스톡 일러스트로 채우지 말 것.
- **아이콘**: lucide-react. 컬러 일러스트 필요 시 최소한으로.
- **모션**: 스크롤 진입 시 은은한 fade-up 정도만(과한 애니메이션 금지).

- **description**: `대행사와 브랜드를 위한 팝업스토어 운영 OS. 구인·전자계약·QR 출퇴근·정산을 한 곳에서. 지금 무료로 시작하세요.`
- **keywords**: 팝업스토어, 팝업 운영, 행사 스태프 구인, 전자계약, 출퇴근 관리, 급여 정산, 대행사 SaaS
- **OG 이미지**: 1200×630 (히어로 비주얼 + 태그라인)
- **호스팅/이식**: SEO를 위해 **클라이언트 전용 SPA 금지**. 정적(SSG) 또는 Laravel Blade로 서버렌더 후, 제품과 동일 토큰/컴포넌트로 구현. 위치는 제품 SPA의 `/` 또는 별도 `landing/` — **결정 필요**.
- **구조화 데이터**: `Organization` + `SoftwareApplication`(가격 포함) JSON-LD
- **성능**: LCP 이미지 최적화(WebP), 폰트 `display=swap`

## 6. 스택 & 이식 제약 (Must)
- 프론트: **Vite + React 19 + TS + Tailwind + shadcn/ui + lucide-react** (제품과 동일)
- 백엔드: **Laravel** (도입 문의 폼 수신·알림)
- 랜딩은 제품 토큰을 그대로 사용. **새 UI 라이브러리·CSS-in-JS 도입 금지**
- 다국어는 이번 범위 아님(한국어). 영문 병기는 선택.
